# راهنمای نصب و اجرا روی ویندوز

برنامه کاملاً **آفلاین** کار می‌کند و فقط روی `127.0.0.1` (همین کامپیوتر) در دسترس است. فایل بکاپ، رمز ZIP و اطلاعات مشتریان به هیچ سرویس اینترنتی ارسال نمی‌شود.

## روش ۱ — فایل اجرایی آماده (پیشنهادی)
1. در GitHub به صفحه **Actions** مخزن `mirza-to-nexa` بروید، آخرین اجرای موفق workflow به نام **CI** را باز کنید و از بخش *Artifacts* فایل `Mirza2Nexa-windows-x64` را دانلود کنید.
2. فایل ZIP دانلودشده را در یک پوشه (مثلاً `C:\Mirza2Nexa`) Extract کنید.
3. فایل `Mirza2Nexa.exe` را اجرا کنید. یک پنجره کنسول باز می‌شود و مرورگر پیش‌فرض صفحه برنامه را باز می‌کند.
   - اگر مرورگر باز نشد، آدرسی را که در کنسول چاپ شده (شامل `?t=...`) در مرورگر وارد کنید.
   - Windows SmartScreen ممکن است به دلیل امضانشدن فایل هشدار دهد: «More info» ← «Run anyway».
4. برای خروج، پنجره کنسول را ببندید. فایل‌های موقت پاک می‌شوند.

## روش ۲ — اجرا از سورس با پایتون
پیش‌نیاز: Python 3.12 یا جدیدتر از python.org (گزینه «Add python.exe to PATH» را فعال کنید).

```powershell
cd C:\path\to\mirza-to-nexa
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install .
mirza2nexa
```

## روش ۳ — ساخت فایل اجرایی روی ویندوز
```powershell
.\.venv\Scripts\Activate.ps1
pip install ".[build]"
pyinstaller --noconfirm --clean packaging\mirza2nexa.spec
python packaging\smoke_test.py dist\Mirza2Nexa\Mirza2Nexa.exe
```
خروجی در پوشه `dist\Mirza2Nexa\` ساخته می‌شود. همین مراحل در CI روی `windows-latest` اجرا و Smoke Test می‌شود.

## مراحل استفاده
1. **بکاپ جدید** ← فایل ZIP بکاپ میرزا را انتخاب کنید (یا بکشید و رها کنید).
2. ساختار ZIP بررسی می‌شود (رمزدار بودن، فایل‌های SQL، فایل‌های نادیده‌گرفته‌شده).
3. رمز ZIP (در صورت وجود)، **واحد پول** و نوع حفاظت بسته را انتخاب کنید:
   - واحد پول: طبق تصمیم مالک NEXA مبالغ میرزا **تومان** هستند. اگر مطمئن نیستید «تعیین‌نشده» را انتخاب کنید؛ بسته ساخته می‌شود اما **مسدود** خواهد بود. هیچ مبلغی خودکار ضرب/تقسیم بر ۱۰ نمی‌شود.
   - حفاظت بسته: «کلید تصادفی جداگانه» (پیشنهادی) یا رمز دلخواه حداقل ۱۲ کاراکتر.
4. **وضعیت تبدیل** پیشرفت واقعی هر مرحله را نشان می‌دهد؛ می‌توانید لغو کنید یا صفحه را ببندید و دوباره باز کنید.
5. **آمار و گزارش**، **صف بررسی** و **پیش‌نمایش خروجی** را بررسی کنید.
6. **دانلود بسته**: فایل `.nxpkg` و فایل کلید `.nxkey` را دانلود کنید و **جداگانه** نگه دارید. کلید فقط در همین نشست در دسترس است.
7. برای مقایسه با بکاپ قبلی، هنگام شروع، عملیات قبلی را در فیلد «مقایسه با» انتخاب کنید (یا در CLI از `--previous-package` استفاده کنید).

## خط فرمان (اختیاری)
```powershell
$env:ZIP_PW = "رمز بکاپ"
mirza2nexa convert backup.zip -o out --money-unit toman --password-env ZIP_PW
mirza2nexa verify out\nexa-migration-XXXX.nxpkg --key-file out\nexa-migration-XXXX.nxkey
mirza2nexa compare old.nxpkg new.nxpkg --old-key-file old.nxkey --new-key-file new.nxkey
```
رمزها از محیط یا ورودی تعاملی خوانده می‌شوند، نه از آرگومان خط فرمان.

## نکات امنیتی
- بسته `.nxpkg` و کلید آن را در یک مکان/پیام ارسال نکنید.
- فایل‌های بکاپ، SQL، رمز و بسته‌ها را هرگز در GitHub قرار ندهید.
- BitLocker را برای دیسک فعال کنید؛ فایل‌های موقت پردازش تا پایان عملیات روی دیسک هستند.
- تا ساخته‌شدن و تست Importer سمت NEXA، این بسته «قابل Import در Production» محسوب نمی‌شود.
