نکات ایمنی

  • برنامه فقط روی آدرس 127.0.0.1 اجرا می‌شود و به اینترنت متصل نمی‌شود؛ هیچ داده‌ای از این کامپیوتر خارج نمی‌شود.
  • رمز فایل ZIP و رمز بسته هرگز ذخیره نمی‌شوند و فقط برای همان عملیات در حافظه نگه داشته می‌شوند.
  • فایل‌های SQL استخراج‌شده در پوشه موقت ایزوله نگهداری و پس از پردازش پاک می‌شوند.
  • بسته خروجی رمزنگاری‌شده است و کلید آن را باید جداگانه و امن نگه دارید.
  • تاریخچه فقط شامل آمار کلی است و نام، شناسه یا مبلغ مشتری در آن ذخیره نمی‌شود.

۳. تنظیمات تبدیل

رمز فایل ZIP

رمز فقط برای همین عملیات استفاده می‌شود و هیچ‌جا ذخیره نمی‌شود.

انتخاب اشتباه واحد، همه موجودی‌ها و مبالغ را ده برابر کم یا زیاد می‌کند. واحد را حتماً با مدیر ربات میرزا تأیید کنید. اگر مطمئن نیستید «تعیین‌نشده» را انتخاب کنید تا مبالغ تا زمان تأیید مسدود بمانند.
